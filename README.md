Progetto in Unreal Engine 5, al fine di creare un breve rendering attorno ad un modello 3D
Contiene : 
- Un modello 3D creato a mano su Blender, successivamente esportato in Unreal Engine.
- Il codice necessario per l'illusione mediante effetto parallasse degli occhi che seguono la camera ed il movimento degli altri oggetti in scena.
- La creazione di landscape e una scena rudimentale per fare da contesto per il rendering.
